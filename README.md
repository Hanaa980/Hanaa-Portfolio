# Hanaa Ragab | Personal Portfolio

A personal portfolio website showcasing my frontend development skills, selected projects, technical background, and contact information.

**Live Demo:** [View Portfolio](https://hanaa-portfolio-rho.vercel.app/)

## Overview

This portfolio was built to present my frontend development journey, highlight my practical projects, and provide an overview of my technical skills and background.

## Features

- **Responsive Design:** Layout optimized for desktop, tablet, and mobile screens.
- **Hero Section:** Introduction with quick navigation and contact links.
- **Projects Showcase:** Displays selected projects with descriptions, categories, and technology badges.
- **Dynamic Project Details:** Dedicated pages for each project with detailed descriptions and information.
- **Project Gallery:** Screenshots carousel showcasing project interfaces across different devices.
- **Technical Highlights:** Displays project features, technology stacks, and key implementation details.
- **About Me:** Introduction, location, and technical skills.
- **Education & Certifications:** Academic background and professional training.
- **Languages:** Overview of language proficiency.
- **Contact Section:** Direct links to email, LinkedIn, GitHub, and WhatsApp.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui
- Base UI
- Lucide React

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Hanaa980/Hanaa-Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Hanaa-Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
